### 功能1: MA均线指标可视化 (主图叠加)

#### 访问方式
1. 打开浏览器访问: http://localhost:3000/analysis
2. 搜索股票（如"平安"或"浦发"）

#### 演示步骤
```

→ http://localhost:3000/analysis

步骤2: 搜索股票
→ 输入框输入: "平安"
→ 选择: 平安银行 (000001.SZ)

步骤3: 启用MA均线
→ 勾选: ☑️ MA均线

步骤4: 观察图表
→ 可见4条彩色均线叠加在K线上
```

#### 预期效果
- ⚪ **MA5** (白色线) - 5日移动平均线
- 🟡 **MA10** (黄色线) - 10日移动平均线
- 🟣 **MA20** (粉色线) - 20日移动平均线
- 🟢 **MA60** (绿色线) - 60日移动平均线

#### 技术指标说明
- **用途**: 判断趋势方向和支撑压力位
- **计算**: Simple Moving Average (SMA)
- **精度**: 小数点后2位
- **数据完整性**: 前N-1个点为null（数据不足期）

### 功能2: 布林带(BOLL)指标可视化 (主图叠加)

#### 访问方式
1. 在股票分析页（已选择股票）
2. 勾选 **"☑️ 布林带"** 复选框
3. 观察K线图上新增的布林带通道

#### 演示步骤
```
步骤1: 在分析页面（延续功能1）
→ 确保已选择股票

步骤2: 启用布林带
→ 勾选: ☑️ 布林带

步骤3: 观察主图
→ K线图上出现上中下三条轨道线
→ 轨道间有渐变色填充
```

#### 预期效果
- 🔴 **BOLL上轨** (红色虚线) - 压力位
- 🔵 **BOLL中轨** (蓝色实线) - 20日均线
- 🟢 **BOLL下轨** (绿色虚线) - 支撑位
- 🎨 **渐变填充** - 通道区域可视化

#### 技术指标说明
- **用途**: 判断价格波动区间和突破信号
- **计算公式**:
  - 中轨 = MA(20)
  - 上轨 = 中轨 + 2×标准差
  - 下轨 = 中轨 - 2×标准差
- **信号**:
  - 价格触及上轨 → 可能回调
  - 价格触及下轨 → 可能反弹
  - 突破上轨 → 强势上涨
  - 跌破下轨 → 弱势下跌

### 功能3: MACD指标副图展示

#### 访问方式
1. 在股票分析页（已选择股票）
2. 勾选 **"☑️ MACD"** 复选框
3. 观察图表底部新增的MACD副图

#### 演示步骤
```
步骤1: 在分析页面
→ 确保已选择股票

步骤2: 启用MACD指标
→ 勾选: ☑️ MACD

步骤3: 观察副图
→ 主K线图下方出现MACD副图
→ 包含柱状图和两条线
```

#### 预期效果
- 📊 **MACD柱状图** (红涨绿跌)
  - 红色: MACD > 0 (多头)
  - 绿色: MACD < 0 (空头)
- 🟡 **DIF线** (黄色) - 快线 (EMA12 - EMA26)
- ⚪ **DEA线** (白色) - 慢线 (DIF的9日EMA)

#### 技术指标说明
- **用途**: 判断买卖时机，识别趋势强弱
- **计算公式**:
  - DIF = EMA(12) - EMA(26)
  - DEA = EMA(DIF, 9)
  - MACD = (DIF - DEA) × 2
- **信号**:
  - DIF上穿DEA = 金叉 (买入信号)
  - DIF下穿DEA = 死叉 (卖出信号)
  - MACD柱状图放大 = 趋势增强

#### 访问方式

2. 勾选 **"☑️ RSI"** 复选框
3. 观察新增的RSI副图

#### 演示步骤
```
步骤1: 在分析页面
→ 确保已选择股票

步骤2: 启用RSI指标
→ 勾选: ☑️ RSI

步骤3: 观察副图
→ 出现RSI曲线图
→ 带有70和30的参考线
→ 有渐变色填充
```

#### 预期效果
- 📈 **RSI曲线** (橙黄色) - 0-100范围
- ⬆️ **超买线** - 70阈值（红色虚线）
- ⬇️ **超卖线** - 30阈值（红色虚线）
- 🎨 **渐变填充** - 强弱区域可视化

#### 技术指标说明
- **用途**: 衡量超买超卖状态
- **计算公式**:
  - RS = 平均涨幅 / 平均跌幅
  - RSI = 100 - (100 / (1 + RS))
- **周期**: 14日
- **信号**:
  - RSI > 70 → 超买，可能回调
  - RSI < 30 → 超卖，可能反弹
  - 50线 → 多空分界线

### 功能5: KDJ指标副图展示

#### 访问方式
1. 在股票分析页（已选择股票）
2. 勾选 **"☑️ KDJ"** 复选框
3. 观察新增的KDJ副图

#### 演示步骤
```
步骤1: 在分析页面
→ 确保已选择股票

步骤2: 启用KDJ指标
→ 勾选: ☑️ KDJ

步骤3: 观察副图
→ 出现三条线（K/D/J）
→ 带有20和80的参考线
```

#### 预期效果
- 🔵 **K线** (蓝色) - 快速随机指标
- 🟡 **D线** (黄色) - K的3日移动平均
- 🔴 **J线** (红色) - 3K - 2D
- 📏 **参考线** - 20/80超买超卖区

#### 技术指标说明
- **用途**: 判断超买超卖和交叉信号
- **计算公式**:
  - RSV = (收盘价 - N日最低) / (N日最高 - N日最低) × 100
  - K = (前K × 2 + RSV) / 3
  - D = (前D × 2 + K) / 3
  - J = 3K - 2D
- **参数**: N=9, M1=3, M2=3
- **信号**:
  - K上穿D = 金叉 (买入)
  - K下穿D = 死叉 (卖出)
  - J > 100 → 超买
  - J < 0 → 超卖
