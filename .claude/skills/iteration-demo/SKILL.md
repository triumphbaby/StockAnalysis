# 迭代成品演示 (Iteration Demo)

展示项目每个迭代完成后的完整可用功能。

## 用途

在每个迭代完成后使用此skill来：
1. 验证前后端链路完整性
2. 展示所有可用功能
3. 提供标准化的测试步骤
4. 生成迭代成果报告

## 使用方法

```
/iteration-demo
```

或

```
/iteration-demo 2
```

指定迭代编号。

## 功能

此skill将会：

1. **检查服务状态** - 验证前端和后端服务是否正常运行
2. **列出迭代功能** - 显示该迭代新增的所有功能
3. **提供访问链接** - 给出直接可访问的URL
4. **演示步骤指导** - 详细的功能演示步骤
5. **API测试示例** - 可执行的API测试命令

## 6. **生成演示报告** - 创建标准化的迭代成果文档

## 输出

- 服务状态检查结果
- 功能清单和访问方式


## 验收标准

每个迭代必须满足：
- ✅ 前端可访问且功能正常
- ✅ 后端API响应正确
- ✅ 端到端功能完整可用
